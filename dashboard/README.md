# แดชบอร์ดยอดขายร้านออนไลน์ (บ้านสบาย ช็อป)

หน้าเว็บแดชบอร์ดที่อ่าน `orders.csv` และ `products.csv` ในเบราว์เซอร์ด้วย PapaParse
ไม่ฝังข้อมูลในโค้ด และไม่ส่งข้อมูลดิบไปที่ใด

> ไฟล์ในโฟลเดอร์นี้คือซอร์สของหน้า (Dashboard artifact ของ Claude) ไม่ใช่เว็บแอปที่เปิดเดี่ยว ๆ ได้
> `index.html` ใช้ `d3` และ `dash.*` ที่รันไทม์ของแดชบอร์ดให้ จึงต้องรันภายใน artifact
> ส่วนตรรกะคำนวณทั้งหมดอยู่ใน `calc.js` ซึ่งไม่พึ่งเบราว์เซอร์ และทดสอบด้วย Node ได้

## ไฟล์

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | หน้าแดชบอร์ด 3 แท็บ: ภาพรวม · วันเมกะเซล · บทสรุปผู้บริหาร |
| `calc.js` | นิยามตัวชี้วัด วันเมกะเซล กำไรขั้นต้น JSON สรุป เนื้อหารายงาน และตัวสร้าง PDF |
| `papaparse.min.js` | PapaParse 5.4.1 (MIT) ใช้อ่าน CSV |
| `check_calc.js` | สคริปต์ตรวจ `calc.js` กับไฟล์ข้อมูลจริง |

## นิยามตัวชี้วัด (ตาม `CLAUDE.md`)

- ยอดขายสุทธิ = `qty × unit_price × (1 − discount_pct/100)` เฉพาะ `status = "จัดส่งสำเร็จ"` ไม่รวม `shipping_fee`
- กำไรขั้นต้น = ยอดขายสุทธิ − `qty × unit_cost` (เชื่อม `products.csv` ด้วย `product_id`)
- AOV = ยอดขายสุทธิ ÷ จำนวนคำสั่งซื้อที่จัดส่งสำเร็จ
- อัตรายกเลิก / อัตราคืน = จำนวนแถวสถานะนั้น ÷ จำนวนแถวทั้งหมดในกลุ่มที่เลือก
- วันเมกะเซล = 3.3, 6.6, 9.9, 10.10, 11.11, 12.12 เทียบกับวันอื่นทั้งหมดในข้อมูล

## บทสรุปผู้บริหาร

- JSON ตัวเลขสรุป ไม่เกิน 30 ค่า และไม่มีข้อมูลดิบ
- เนื้อหา PDF สร้างจากแม่แบบข้อความ เติมเฉพาะตัวเลขจาก JSON รวมไม่เกิน 300 คำ และแต่ละหัวข้อไม่เกิน 100 คำ
  หน้าจะตรวจซ้ำก่อนเปิดปุ่ม Export ถ้ามีตัวเลขนอก JSON หรือเกินจำนวนคำ
- PDF เป็นภาพของหน้า (เพื่อให้สระและวรรณยุกต์ไทยถูกต้อง) พร้อมชั้นข้อความโปร่งใสให้เลือกและคัดลอกได้

## ตรวจ `calc.js`

```bash
node dashboard/check_calc.js data
```

ต้องมี `data/orders.csv` และ `data/products.csv` สคริปต์จะลองตัวกรองภูมิภาค × หมวดสินค้าทุกแบบ
แล้วตรวจว่าเนื้อหารายงานไม่เกินจำนวนคำ และไม่มีตัวเลขที่ไม่อยู่ใน JSON
